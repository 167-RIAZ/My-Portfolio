### README for My-Portfolio

## Project Description
My-Portfolio is a personal portfolio website developed primarily using TypeScript. It showcases my projects, skills, and professional experience. The website is hosted on [Vercel](https://my-portfolio-cv6j.vercel.app/).

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/167-RIAZ/My-Portfolio.git
   ```
2. Navigate to the project directory:
   ```sh
   cd My-Portfolio
   ```
3. Install dependencies:
   ```sh
   npm install
   ```

## Usage
1. Start the development server:
   ```sh
   npm start
   ```
2. Open your browser and go to `http://localhost:3000` to view the website.
